What does this tool do?

This tool detects hardcoded URLs inside source code or config files. Hardcoded URLs are a security risk — they should be stored in environment variables or config files instead.

  • Choose a file or paste code, or use Bulk Scan for multiple files.

  • Click ⚡ Scan — every line is scanned with advanced regex patterns.

  • Review results — line number, type badge (HTTP/HTTPS/Localhost/IP), risk score.

  • AI Analyzer — get Python-grade analysis: duplicates, env-var suggestions, token detection.

  • Risk Report — security risk scoring from LOW → CRITICAL for each URL.

  • Charts — visual breakdown of URL types, risk distribution, domain frequency.

  • Admin Panel — login as admin to manage history, whitelist domains, configure settings.

  • Export — download as .txt, .csv, or .json report.
